# JARVIS PRIME — что нужно достать и куда вставить

Секреты НЕ присылайте в чат. Вставляйте их в файл `prime\.env` (создайте его из `prime\.env.example`).
Файл `.env` закрыт в `.gitignore` и в архив не попадает.

Проверить, что уже готово, и что ещё не хватает:

```
python prime\tools\check_setup.py
```

## 1. Claude API (мозг для сложных задач, код, анализ экрана, презентации)
- Где: https://console.anthropic.com → API Keys → Create key
- Нужно: платный баланс на аккаунте. Бюджет в день задаётся в `config\settings.py` (по умолчанию 1 доллар).
- Вставить в `.env`: `ANTHROPIC_API_KEY=sk-ant-...`
- Без ключа: работает Groq/локальный режим, Claude отключён.

## 2. Telegram-бот (пульт с телефона)
- Токен: откройте @BotFather в Telegram → `/newbot` → скопируйте токен.
- Ваш числовой ID: уже известен для @jarvismr_bot (тот же, что в настройках Джарвиса), либо узнайте у @userinfobot.
- Вставить в `.env`:
  - `PRIME_TELEGRAM_TOKEN=123456:ABC...`
  - `PRIME_TELEGRAM_OWNER=ваш_id`
- Без них: Telegram-пульт выключен, остальное работает.

## 3. Умный дом через Home Assistant (свет, розетки, климат)
- Нужен Home Assistant в сети (https://www.home-assistant.io/installation/).
- Токен: в Home Assistant → профиль (внизу слева) → «Долгосрочные токены доступа» → Создать токен.
- Адрес: например `http://192.168.1.10:8123` (IP вашего Home Assistant).
- Вставить в `.env`: `PRIME_HA_URL=...`, `PRIME_HA_TOKEN=...`

## 4. Телевизор Samsung (включение по сети)
- IP телевизора: телевизор → Настройки → Сеть → Состояние сети, либо список устройств в роутере.
- MAC-адрес: там же, или в роутере.
- Включить на телевизоре: Настройки → Общие → Диспетчер устройств → Wake on LAN (если есть).
- Вставить в `config\devices.yaml`: поля `ip` и `mac` для `tv_samsung`. Это не секрет.

## 5. Уведомления на телефон и часы (ntfy)
- Установить приложение ntfy на телефон (Google Play / App Store).
- Придумать длинное имя канала, например `jarvis-ваше-слово-12345`, подписаться на него в приложении.
- Вставить в `.env`: `PRIME_NTFY_TOPIC=jarvis-ваше-слово-12345`
- Часы: уведомления ntfy идут на телефон, а телефон зеркалит их на часы штатно.

## 6. Языковая модель локально (запасной режим без интернета)
- Установить Ollama: https://ollama.com/download
- Скачать модель в PowerShell: `ollama pull qwen2.5:7b`
- Ничего вставлять не нужно: `prime` сам найдёт Ollama на 127.0.0.1:11434.

## 7. Браузер для веб-агента
- В папке `prime`: `pip install playwright`, затем `playwright install chromium`
- Ничего вставлять не нужно.

## 8. Экран и Claude Vision (зрение)
- Установить: `pip install mss pillow`
- Ключ Claude из пункта 1 нужен для анализа картинки.

## 9. Bluetooth-наушники
- Укажите часть имени наушников в `config\devices.yaml` → `headphones.name_contains`
- Установить: `pip install bleak`
- Bluetooth на ноутбуке должен быть включён.

## 10. Голос для презентации на японском и английском
- Ключей не нужно, работает через интернет (`edge-tts`), установка: `pip install edge-tts`

## Что я сделаю, когда пришлёте (или вставите в `.env`)
- Claude (с Thinking и кэшем промптов), проверка ключа и бюджета.
- Telegram-пульт: проверка владельца и подтверждение опасных действий кнопками.
- Home Assistant: включение света и розеток голосом.
- Телевизор: проверка, что он отвечает, и включение по сети.
- ntfy: отправка тестового уведомления.
- Полный прогон всех тестов с реальными сервисами и отчёт по каждой строке.
