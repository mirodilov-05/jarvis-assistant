# Джарвис — личный голосовой ассистент для Windows 11

Джарвис слушает «Джарвис», понимает русскую речь (и узбекский), ведёт дела, цели и заметки, управляет программами и телевизором Samsung, читает WhatsApp, Telegram и почту, помнит ваши факты, учится на поправках и делает доклады на весь экран.

Всё, что касается личных данных, хранится на вашем компьютере. Облако (Groq, Gemini) используется только для распознавания речи и ответов, и его можно выключить.

**Инструкции по каждому разделу: [INSTRUCTIONS.md](INSTRUCTIONS.md)** (те же инструкции есть внутри приложения: раздел «Инструкции»).

## Установка на новый ноутбук

1. На странице GitHub нажмите **Code → Download ZIP** и распакуйте архив, например в `C:\Jarvis`. Не используйте путь с русскими буквами и не храните проект в OneDrive.
2. Дважды щёлкните **INSTALL.bat**. Если Windows покажет «Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае** (файл скачан из интернета, поэтому Windows спрашивает). Сначала установщик проанализирует ноутбук и покажет список того, что есть и чего не хватает. Ничего не ставится, пока вы не ответите «д».
3. После установки откроется окно Джарвиса со знакомством из пяти шагов: голос, характер и цвет, работа с облаком или без интернета, ваш город, **изучение вашего компьютера**.
4. Вставьте бесплатный ключ Groq: **Настройки → Ключи и облако**.

Джарвис не знает заранее ничего ни о вас, ни о вашем компьютере. На последнем шаге знакомства он один раз изучает этот компьютер (программы, игры, браузер, музыку, мессенджеры, имена файлов) и дальше открывает то, что есть именно у вас, и запоминает ваши слова. Всё хранится только у вас в папке `data`.

Только посмотреть, ничего не меняя:

```
powershell -ExecutionPolicy Bypass -File install.ps1 -CheckOnly
```

Требования: Windows 10/11 64-бит, 8 ГБ памяти (лучше 16), около 8 ГБ свободного места. Видеокарта NVIDIA ускоряет распознавание, но не обязательна.

## Что умеет

- **Голос.** Узнаёт ваш голос, перебивается, сообщает о новых письмах и сообщениях.
- **Дела и цели.** Дела со сроками и напоминаниями, цели с ежедневными шагами, лимиты времени на программы, фокус-щит против отвлечений.
- **Компьютер.** Открыть и закрыть программы, громкость и яркость, диспетчер задач, анализ и безопасная оптимизация ноутбука с отменой.
- **Телевизор Samsung.** Включение, громкость, каналы, YouTube, пульт.
- **Связь.** WhatsApp (QR-код), Telegram-бот для управления с телефона, Telegram-аккаунт, почта, календарь.
- **Память.** Факты о вас, поиск в ваших документах (PDF, Word, текст), обучение на поправках и оценках 👍 👎, стадии отношений.
- **Безопасность.** Проверка открытых портов, блокировка IP с вашим подтверждением, VPN через WireGuard, геолокация IP по запросу.
- **Презентация.** Доклад за месяц на весь экран, управляется голосом и кнопками.

## Интерфейс

- **Главная.** Ядро Джарвиса в центре и ваши виджеты вокруг. Виджеты можно переставлять, менять размер и вид, скрывать или добавлять. Есть режимы «Ядро и виджеты», «Сетка» и «Только ядро».
- **Дела, Цели, Команды, Память, Презентация.** Отдельные разделы для повседневной работы.
- **Настройки.** Голос, мессенджеры и почта, календарь, погода, ключи и облако, компьютер, характер, данные. Каждый раздел объясняет, что делает настройка.
- **Внешний вид.** Пять цветовых тем (у каждой своя форма вокруг ядра), стиль карточек, плотность, раскладки, перенос настроек в файл.
- **Поиск команд.** Ctrl+K открывает поиск по разделам и действиям, а также отправку команды Джарвису.

## Структура проекта

| Папка или файл | Что внутри |
|---|---|
| `assistant.py` | сервер окна, голосовой цикл, все API |
| `core.py`, `plugins/` | маршрутизатор команд и навыки |
| `agent.py`, `cloud.py` | мозг: выбор инструментов и облачные вызовы |
| `cognition/` | память, личность, документы, защита сети, голос |
| `learning/` | обучение на поправках |
| `web/` | интерфейс: `index.html`, `app.css`, `core.js` (ядро), `app.js`, `pages.js`, `help.js` |
| `prime/` | JARVIS PRIME OS: телевизор, карточки для учёбы, Telegram-пульт |
| `prime/tests/`, `relay/` | тесты и релей для включения ноутбука |
| `install.ps1`, `INSTALL.bat`, `optimizer.py`, `setup_doctor.py` | установка, анализ и оптимизация |

## Тесты

```
cd prime\tests
..\..\.venv\Scripts\python.exe -X utf8 test_stage31_audit.py
```

Полный прогон: все файлы `prime/tests/test_stage*.py` из корня проекта. Тесты не трогают ваш телевизор, почту и историю: внешние вызовы подменяются.

## Конфиденциальность

- Ключи и пароли хранятся в диспетчере учётных данных Windows, не в файлах.
- Личные данные (`data/`, голосовой отпечаток, история, база памяти, сессии) не попадают в репозиторий: они перечислены в `.gitignore`.
- Облако получает только ваши команды и распознанную речь. Обычный разговор в комнате не отправляется.
- Геолокация IP и блокировка выполняются только по вашему прямому запросу.
