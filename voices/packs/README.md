# Голосовые паки персонажей

Каждая папка здесь — один пак. Выбрать его можно в HUD: ⚙ Настройки → «Голосовой пак».

```
voices/packs/<имя пака>/
    start/   *.wav — играет при запуске вместо приветствия синтезатором
    ok/      *.wav — короткая фраза, когда команда выполнена («Будет сделано, сэр»)
    error/   *.wav — когда не получилось
```

Если в папке нет файлов, Джарвис говорит обычным голосом (Piper). Длинные ответы всегда читает синтезатор.

Файлы — WAV (PCM). Запишите свои фразы или используйте клипы, на которые у вас есть права.
Реплики из фильмов и игр (Джарвис, BT-7274, Мориарти) — чужие записи: в паки их не кладём.
